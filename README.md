## My Scripts

A collection of scripts that I wrote or modified from someone else

(Files licensed under different terms than GPLv3 have the license embedded in the file.)

- [fbuku](https://github.com/jbrubake/fzf-scripts/blob/master/bin/fbuku) - manage buku bookmarks with fzf
- [fctags](https://github.com/jbrubake/fzf-scripts/blob/master/bin/fctags) - manage ctags with fzf
- [fdocker](https://github.com/jbrubake/fzf-scripts/blob/master/bin/fdocker) - manage docker containers with fzf
- [femoji](https://github.com/jbrubake/fzf-scripts/blob/master/bin/femoji) - use fzf to select emoji
- [fgit-stash](https://github.com/jbrubake/fzf-scripts/blob/master/bin/fgit-stash) - Use fzf to manage git stashes
- [fgrep](https://github.com/jbrubake/fzf-scripts/blob/master/bin/fgrep) - Interactive grep using fzf
- [fkill](https://github.com/jbrubake/fzf-scripts/blob/master/bin/fkill) - kill processes selected using fzf
- [fpass](https://github.com/jbrubake/fzf-scripts/blob/master/bin/fpass) - manage a pass(1) database using fzf
- [fpickfont](https://github.com/jbrubake/fzf-scripts/blob/master/bin/fpickfont) - use fzf to preview fonts
- [fpkg](https://github.com/jbrubake/fzf-scripts/blob/master/bin/fpkg) - Use fzf to select and install packages
- [fscp](https://github.com/jbrubake/fzf-scripts/blob/master/bin/fscp) - Use fzf to select and download remote files using scp
- [ftmux](https://github.com/jbrubake/fzf-scripts/blob/master/bin/ftmux) - use fzf to switch to or kill tmux sessions, windows and panes
- [fwifi](https://github.com/jbrubake/fzf-scripts/blob/master/bin/fwifi) - use fzf to connect to WiFi access points
- [fzfmenu](https://github.com/jbrubake/fzf-scripts/blob/master/bin/fzfmenu) - Use fzf as a dmenu replacement
